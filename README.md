# Startup Investment Analysis – Shark Tank India

## 📌 Project Overview

This project analyzes startup investment patterns using the Shark Tank India dataset.

The analysis focuses on:
- Deal success and failure
- Total and average investment
- Episode-wise investment trends
- Shark-wise deal participation
- Actual investment by each shark
- Top-funded startups

The project was developed using Python in Google Colab.

## 🎯 Objectives

- Analyze startup deal outcomes.
- Understand investment patterns across episodes.
- Compare shark participation and investment.
- Identify startups receiving the highest investment.
- Present findings using clear data visualizations.

## 🛠️ Tools & Technologies

- Python
- Pandas
- Matplotlib
- Google Colab
- CSV Dataset

## 📊 Dataset

The dataset contains **117 startup pitches** with **28 columns**, including:

- Startup/brand name
- Pitch and episode information
- Amount asked
- Equity asked
- Deal amount
- Deal equity
- Deal valuation
- Shark participation
- Number of sharks invested
- Amount per shark
- Equity per shark

## 🔎 Analysis Performed

1. Loaded and explored the Shark Tank India dataset.
2. Calculated the total number of startups and deals.
3. Analyzed closed and non-closed deals.
4. Calculated total and average investment.
5. Analyzed investment by episode.
6. Compared the number of deals associated with each shark.
7. Calculated actual investment by shark using the amount-per-shark field.
8. Identified the top 10 startups by investment amount.
9. Created charts using Matplotlib.

## 📊 Visualizations

The project includes visualizations for:

- Deal Status

## 💡 Conclusion

The analysis provides an overview of startup investment activity in the available Shark Tank India dataset. It shows the number of successful deals, overall investment, shark participation, and the startups receiving the highest investment.

The analysis demonstrates how Python-based data analysis and visualization can be used to extract meaningful insights from startup investment data.
